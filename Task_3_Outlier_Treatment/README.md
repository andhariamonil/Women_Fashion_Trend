# Task 3 — Outlier Detection and Treatment

## Objective
Detect numerical outliers using IQR, Z-score, and DBSCAN, then apply configurable domain-aware treatment.

## Input
`data/interim/womens_clothing_standardized.csv` (generated by Task 2).

## Run
Run Task 1 and Task 2 first, then open `notebooks/Task_3_Outlier_Treatment.ipynb` and run all cells.

## Output
- `data/processed/womens_clothing_final.csv`
- `reports/task3_row_outlier_flags.csv`
- `reports/task3_feature_outlier_summary.csv`
- `logs/task3_treatment_log.json`

## Treatment policy
The notebook caps selected monetary, sales, review-count, and inventory measures using IQR fences. It does not automatically delete outlier rows. Rating is checked against the expected 1–5 domain. DBSCAN noise labels are treated as candidates for review, not proof of invalid data.
