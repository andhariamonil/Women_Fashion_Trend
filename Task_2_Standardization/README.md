# Task 2 — Data Standardization

## Objective
Standardize column names and data types using safe, auditable conversions.

## Input
`data/interim/womens_clothing_cleaned.csv` (generated by Task 1).

## Run
Run Task 1 first, then open `notebooks/Task_2_Standardization.ipynb` and run all cells.

## Output
- `data/interim/womens_clothing_standardized.csv`
- `logs/task2_conversion_log.json`

## Standardization policy
Column names are converted to lowercase snake_case. Known numeric and boolean fields are parsed explicitly. Remaining text fields are converted to numeric only when at least 95% of non-null values parse successfully. Unrecognized values are counted in the conversion log.
